Shoot the blade flat-on and square, off the keyring, with a credit card (ID-1) in frame for scale. Perspective skew is the main source of error.

  1. Hit Calibrate and click the blade's uncut top edge, then its bottom edge. Height, position and tilt are all set for you.
  2. The datum is the flat run of blade top between the shoulder and the first cut — not the peaks between cuts, which get truncated when neighbouring cuts are deep. Aim high by one step and every cut reads one number too shallow.
  3. Depths measure up from the blade bottom, so 0 is the shallowest cut and the highest line.
  4. Drop opacity to ~60% and read the numbered line each cut valley bottoms out on. Cuts number from the bow/shoulder end.

Width is decoupled from height so you can stretch the template across the blade without disturbing the depth scale.
